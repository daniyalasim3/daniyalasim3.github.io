Daniyal's Auction E-Commerce Website

A full-stack auction website developed using Java, JSP, Servlets, JDBC, SQLite, and WebSockets.

Features:

  • Forward and Dutch auctions
  • Real-time bidding using WebSockets
  • User authentication and session management
  • Bid history and auction tracking
  • Auction completion and winner determination

Tech Stack:

  • Java
  • JSP / JSTL
  • Java Servlets
  • JDBC / SQLite
  • WebSockets
  • HTML / CSS / JavaScript
  • Apache Tomcat 9
  • Maven
